# Archived local application sources

Source-only snapshots preserved on 22.10.2026 before removing the old local projects. Each subfolder contains the exact final small source/configuration files from its corresponding local checkout, including changes that were not committed there. To restore a variant, copy those files into a normal project checkout and reinstall its dependencies. Model weights, training images, virtual environments and generated results are intentionally excluded.

The Find-Your-Karas training script and dataset configurations remain in the Training directory on its archive branches. Previous default-branch application code is preserved separately from these source snapshots.
